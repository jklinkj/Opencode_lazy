# OpenCode 在线安装操作指南

这份指南用于帮助你完成 OpenCode 在线安装、打开网页版，以及在需要时安装桌面版。
如果安装过程中出现问题，请保留 `reports` 文件夹，不要删除。

## 先记住这 3 个入口

- `launcher/start.cmd`：首次安装时使用
- `launcher/open-opencode-web.cmd`：安装完成后打开 OpenCode Web
- `launcher/install-desktop.cmd`：可选，用于安装 Desktop 客户端

大多数情况下，使用顺序是：

1. 先双击 `launcher/start.cmd`
2. 安装完成后双击 `launcher/open-opencode-web.cmd`
3. 如果需要桌面版，再双击 `launcher/install-desktop.cmd`

## 开始前先看这几条

- 先把整个压缩包完整解压，不要在压缩包内部直接运行
- 请把安装包放在本地磁盘的普通文件夹中，不要放在网盘同步目录里
- 不要修改目录结构，不要重命名 `launcher`、`scripts`、`profiles` 等文件夹
- 安装过程中尽量保持网络可用，不要中途断网
- 不要直接运行 `scripts` 目录中的 `.ps1` 文件

## 第一次使用：完成安装

### 第 1 步：打开 `launcher` 文件夹

现在要做什么：

- 打开已经解压好的安装包目录
- 打开其中的 `launcher` 文件夹
- 找到 `start.cmd`

正常会看到什么：

- `launcher` 文件夹中可以看到 `start.cmd`
- 同一个目录里还会看到 `open-opencode-web.cmd` 和 `install-desktop.cmd`

如果失败怎么办：

- 如果找不到这些文件，通常是没有解压完整，或者打开了错误的目录
- 先回到安装包根目录重新检查，不要继续点 `scripts` 里的文件

[截图位：launcher 文件夹中的 start.cmd]

### 第 2 步：双击 `start.cmd`

现在要做什么：

- 双击 `launcher/start.cmd`
- 看到黑色窗口后不要关闭，等待它自行运行完成

正常会看到什么：

- 会弹出一个黑色窗口
- 窗口中会显示安装进度
- 过程里会进行检查、下载和安装

如果失败怎么办：

- 如果窗口一闪而过、卡住很久或提示错误，先不要删除任何文件
- 回到安装包根目录，查看是否已经出现 `reports` 文件夹
- 如果已经有 `reports`，请先保留它

[截图位：start.cmd 运行中的窗口]

### 第 3 步：确认安装结果

现在要做什么：

- 等待安装窗口结束
- 回到安装包根目录，查看 `reports` 文件夹

正常会看到什么：

- 安装成功时，窗口会显示完成提示
- `reports` 文件夹里会新增一个本次运行的结果目录

如果失败怎么办：

- 即使安装失败，也不要删除 `reports`
- 后续反馈问题时，需要把整个 `reports` 文件夹一并提供

[截图位：安装包根目录中的 reports 文件夹]

## 安装完成后：打开 OpenCode 网页版

### 第 1 步：双击 `open-opencode-web.cmd`

现在要做什么：

- 回到 `launcher` 文件夹
- 双击 `open-opencode-web.cmd`

正常会看到什么：

- 会弹出“选择文件夹”的窗口
- 之后浏览器会打开 OpenCode Web

如果失败怎么办：

- 如果提示未检测到 OpenCode，说明前面的安装没有完成
- 请先重新检查安装步骤，并保留 `reports`

[截图位：open-opencode-web.cmd 启动后的选择窗口]

### 第 2 步：选择工作文件夹

现在要做什么：

- 在弹出的窗口中选择一个你准备使用的工作文件夹
- 如果还没有，可以先在桌面新建一个文件夹再选中它

正常会看到什么：

- 选中后，OpenCode 会使用这个文件夹作为当前工作目录

如果失败怎么办：

- 如果暂时不知道该选哪个，先选择一个新建的空文件夹
- 不建议直接选择整个磁盘或系统目录

[截图位：选择工作文件夹]

### 第 3 步：在浏览器中继续

现在要做什么：

- 等待浏览器自动打开
- 按页面提示继续登录或连接

正常会看到什么：

- 浏览器中出现 OpenCode 页面
- 如需登录，页面会继续提示下一步操作

如果失败怎么办：

- 如果浏览器没有自动打开，先看黑色窗口中是否有报错
- 同时保留 `reports` 文件夹，方便后续反馈

[截图位：浏览器中的 OpenCode 页面]

## 可选：安装 Desktop 客户端

桌面版不是必需项。
如果你先使用网页版，可以跳过这部分。

### 第 1 步：双击 `install-desktop.cmd`

现在要做什么：

- 打开 `launcher` 文件夹
- 双击 `install-desktop.cmd`

正常会看到什么：

- 脚本会先查找或在线获取桌面安装器
- 随后启动 Desktop 安装程序

如果失败怎么办：

- 桌面版安装失败不会影响网页版使用
- 请保留 `reports` 文件夹，并记录屏幕上的报错信息

[截图位：install-desktop.cmd 启动后的窗口]

### 第 2 步：按安装程序提示完成安装

现在要做什么：

- 按桌面安装程序的提示继续
- 安装完成后，从开始菜单打开 OpenCode Desktop

正常会看到什么：

- 安装程序正常结束
- Desktop 可以从开始菜单启动

如果失败怎么办：

- 如安装程序返回错误，请记录错误提示
- 同时保留安装包目录和 `reports` 文件夹

## 遇到问题时怎么处理

### 出错时不要做这些事

- 不要删除安装包目录
- 不要删除 `reports` 文件夹
- 不要自己修改 `scripts`、`profiles`、`manifests` 中的文件

### 需要提供哪些信息

反馈问题时，至少需要提供：

- 你运行的是哪个入口文件
- 问题发生在第几步
- 屏幕上看到的报错文字
- 整个 `reports` 文件夹

可以直接复制下面这段话：

> 我在使用 OpenCode 在线安装包时遇到了问题。  
> 我运行的是：`_____`  
> 出错步骤是：`_____`  
> 屏幕提示是：`_____`  
> 我已附上整个 `reports` 文件夹。  

## 附录：供维护人员参考

### `scan-only.cmd` 是做什么的

- 只做检查，不做安装
- 运行后同样会生成 `reports` 目录
- 适合先判断环境状态

### `configure-opencode.cmd` 是做什么的

- 用于写入 OpenCode 配置
- 需要带参数运行
- 不属于首次安装的主流程入口
